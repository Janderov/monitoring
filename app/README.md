# Monitor: приложение для macOS

Значок в строке меню, который раз в минуту опрашивает агентов на серверах, хранит
историю в SQLite и присылает уведомления macOS о проблемах.

## Установка

1. Скачайте артефакт `Monitor-app` из последнего зелёного запуска CI (вкладка Actions,
   workflow `app`) и распакуйте `Monitor.zip`.
2. Перенесите `Monitor.app` в «Программы». Приложение подписано без аккаунта
   разработчика, поэтому один раз снимите карантин:
   ```
   xattr -dr com.apple.quarantine /Applications/Monitor.app
   ```
3. Запустите и добавьте серверы кнопкой «Добавить сервер». Приложение само зайдёт на
   сервер по SSH (ключи и псевдонимы из `~/.ssh/config` подхватываются), поставит агента,
   откроет его порт в ufw и сохранит токен и отпечаток. На вопрос macOS про уведомления
   ответьте «Разрешить».

Токены агентов хранятся в Связке ключей, а не в `servers.json`. Приложение подписано без
аккаунта разработчика, поэтому после установки новой сборки macOS один раз спросит, можно
ли ему читать Связку ключей: ответьте «Разрешать всегда». Токен, вписанный в файл вручную,
приложение при запуске переносит в Связку ключей и убирает из файла.

## servers.json

Файл можно править и руками (кнопка «servers.json» в меню, затем «Перечитать»).

```json
{
  "servers": [
    {
      "id": "nl-1",
      "name": "Нидерланды VPN",
      "host": "203.0.113.10",
      "port": 9443,
      "fingerprint": "54:69:04:…",
      "group": "Нидерланды",
      "tags": ["vpn"],
      "thresholds": {"disk_percent": 85}
    }
  ]
}
```

### Сайты

В тот же файл можно добавить список `sites`. Приложение само раздаст проверки агентам, и
каждый сайт будет проверяться раз в минуту со всех серверов (или только с перечисленных в
`from`). Срок регистрации домена приложение узнаёт у регистратора (RDAP, для .ru и .su
через WHOIS) два раза в сутки.

```json
  "sites": [
    {"id": "biotech", "name": "Биотех", "url": "https://biotech.ru", "group": "Россия"},
    {"id": "shop", "name": "Магазин", "url": "https://shop.example.com", "from": ["nl", "us"]}
  ]
```

`thresholds` необязателен. Поля и значения по умолчанию: `disk_percent` 90,
`cpu_percent` 90, `cpu_minutes` 5, `memory_percent` 90, `tls_days` 14, `domain_days` 14.
У сайтов из порогов учитываются `tls_days` и `domain_days`.

## Оповещения

| Событие | Важность | Когда приходит |
|---|---|---|
| агент не отвечает | критично | 3 неудачных опроса подряд |
| VPN-контейнер остановлен, сервис не запущен или порт закрыт, сайт недоступен | критично | 2 опроса подряд |
| диск, память выше порога; контейнер unhealthy; SSL истекает | предупреждение | 2 опроса подряд |
| CPU выше порога | предупреждение | `cpu_minutes` опросов подряд |
| сайт недоступен со всех серверов | критично | 2 опроса подряд |
| сайт недоступен только с части серверов (похоже на блокировку) | предупреждение | 2 опроса подряд |
| SSL сайта или домен истекает через `tls_days` / `domain_days` | предупреждение | сразу (домен), 2 опроса (SSL) |

Пока проблема не решена, напоминание приходит раз в 30 минут. Когда всё в порядке
два опроса подряд, приходит одно «снова в норме» (после падения сервера достаточно
одного удачного опроса). Если недоступны сразу все серверы, считается, что пропала
сеть на самом Mac, и оповещений нет.

## Данные

Всё лежит в `~/Library/Application Support/Monitor/`: `servers.json` (только для
владельца; перед каждым изменением из приложения рядом сохраняется `servers.json.bak`)
и `monitor.sqlite`. Поминутные данные хранятся 30 дней, почасовые и журнал оповещений год.
Для переезда на Mac mini скопируйте папку; токены останутся в Связке ключей старого Mac,
поэтому на новом нажмите у каждого сервера «Переустановить агента»: приложение заберёт
прежний токен с сервера.

После сна Mac приложение забирает у агентов пропущенную историю (до 24 часов).

## Разработка

```
swift test                      # ядро, работает и на Linux
../agent/scripts/dist.sh        # агент для установки на серверы (нужен Go)
scripts/build-app.sh            # dist/Monitor.app с агентом внутри, только на Mac
```

`MonitorCore` содержит модели, клиент агента, правила оповещений, SQLite и опрос;
`MonitorUI` содержит модель приложения `AppModel` и представления SwiftUI;
`Monitor` содержит точку входа и уведомления macOS.
