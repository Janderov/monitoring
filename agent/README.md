# monitor-agent

Агент для серверов Ubuntu. Раз в минуту собирает:

- метрики сервера из `/proc`: CPU, память, нагрузка, диски, сеть, аптайм;
- топ процессов по CPU и памяти;
- Docker-контейнеры и AmneziaVPN: число клиентов, активные клиенты (рукопожатие за последние
  3 минуты), трафик по каждому клиенту с именами из приложения AmneziaVPN;
- PostgreSQL и MySQL: процесс запущен, порт отвечает (агент находит их при установке);
- проверки сайтов и соседних серверов, список которых задаёт приложение на Mac.

Последние 24 часа хранятся в памяти и отдаются приложению на Mac по HTTPS. Ничего на сервере
не меняет: внутри контейнеров AmneziaVPN выполняются только `wg show` и чтение списка клиентов.

## Сборка и тесты

```
cd agent
go test ./...
GOOS=linux GOARCH=amd64 go build -ldflags "-X main.version=0.1.0" -o monitor-agent ./cmd/monitor-agent
```

## Установка на сервер (пока вручную)

```
scp monitor-agent deploy/install.sh deploy/monitor-agent.service root@SERVER:/tmp/
ssh root@SERVER 'cd /tmp && ./install.sh --binary ./monitor-agent --token <ключ> --host <IP сервера>'
```

Ключ генерирует приложение на Mac (до его появления подойдёт `openssl rand -hex 32`).
Скрипт печатает отпечаток сертификата, его нужно сохранить в приложении. Порт по умолчанию 9443.

## API

Все запросы требуют заголовок `Authorization: Bearer <ключ>`.

| Запрос | Ответ |
|---|---|
| `GET /v1/health` | версия агента и время его работы |
| `GET /v1/snapshot` | последний снимок: CPU, память, нагрузка, диски, сеть, аптайм, контейнеры |
| `GET /v1/history?since=<unix>` | снимки новее `since`, по 500 за раз; `more: true` значит, что нужно запросить ещё |
| `GET /v1/checks` | список сайтов и серверов, которые проверяет агент |
| `PUT /v1/checks` | заменить этот список, результаты появятся в поле `checks` следующих снимков |

Пример списка проверок:

```json
{"targets": [
  {"id": "site-shop", "kind": "http", "url": "https://example.ru"},
  {"id": "srv-nl", "kind": "tcp", "host": "203.0.113.7", "port": 9443}
]}
```

`http` проверяет код ответа (ошибка с 400), время ответа и срок SSL-сертификата. `tcp` проверяет,
что порт отвечает, и измеряет задержку (пинг по ICMP требует прав root, поэтому не используется).

Проверка с Mac:

```
curl -k -H "Authorization: Bearer $TOKEN" https://SERVER:9443/v1/snapshot
```
