# Платформа мониторинга серверов и сайтов: требования

Версия 1.0 · 5 октября 2026 · заказчик и единственный пользователь: Михаил

Документ собран по итогам интервью. Решения пользователя помечены как принятые, мои технические предложения помечены «предложение» и могут меняться при проектировании.

---

## 1. Цель

Одно приложение на macOS, в котором видно состояние всех серверов и сайтов, приходят оповещения о проблемах и одним кликом можно зайти на сервер по SSH. Новые серверы и сайты добавляются без правки кода. Приложение только для личного использования, продавать или раздавать его не планируется.

## 2. Текущая инфраструктура

| Что | Сейчас | Ожидание |
|---|---|---|
| Серверы | до 10, VPS | до 10 в течение года, возможно появятся свои физические |
| Хостинги | FirstVDS (Россия), Vultr (США); есть серверы в Нидерландах | список растёт |
| ОС | Ubuntu | только Linux |
| Доступ | SSH по ключу и по паролю | постепенно перейти на ключи |
| Сервисы | AmneziaVPN, сайты (3–4, на российских серверах), PostgreSQL, MySQL | |

Агента можно ставить на все серверы.

## 3. Архитектура

```
   Серверы (США, NL, RU)                      Mac (позже Mac mini 24/7)
 ┌───────────────────────┐   HTTPS-опрос   ┌──────────────────────────────┐
 │ агент                 │ ◄────────────── │ «мозг»: опрос агентов,       │
 │  · метрики сервера    │   раз в минуту  │ проверки, хранение истории,  │
 │  · AmneziaVPN, БД     │                 │ правила оповещений           │
 │  · проверки сайтов и  │                 │                              │
 │    соседних серверов  │                 │ UI: строка меню + окно       │
 │    из своей страны    │                 │ Уведомления macOS            │
 └───────────────────────┘                 └──────────────────────────────┘
```

Принятые решения:
- «Мозг» работает внутри приложения на Mac. Позже переезжает на Mac mini, который работает круглосуточно; перенос должен быть простым (скопировать базу и настройки).
- Mac сам опрашивает агентов по зашифрованному HTTPS (Mac стоит за домашним роутером, входящие соединения к нему не нужны). VPN для работы мониторинга не требуется.
- Агенты на серверах в разных странах проверяют сайты и друг друга, чтобы видеть проблемы доступности из конкретной страны (например, блокировку в России).

Важное ограничение: пока «мозг» на ноутбуке, при закрытой крышке или выключенном Mac проверки и оповещения не работают. Агенты продолжают собирать метрики, поэтому после включения Mac история за пропущенное время подтянется (предложение: агент хранит буфер минимум за 24 часа).

Предложение по технологиям: приложение на Swift и SwiftUI, история в SQLite; агент одним бинарным файлом на Go как служба systemd.

## 4. Что мониторится

### 4.1 Серверы (через агента)
- жив или не жив (агент отвечает, сервер пингуется);
- CPU, оперативная память, диск (по разделам);
- сеть: трафик входящий и исходящий, задержка между серверами;
- процессы и Docker-контейнеры (запущены или нет, потребление);
- аптайм и факт перезагрузки.

### 4.2 Сервисы на серверах
- **AmneziaVPN:** работает ли сервис или контейнер, число подключённых клиентов, трафик (общий и по клиентам, если это возможно получить).
- **PostgreSQL и MySQL:** запущен ли процесс, отвечает ли порт; предложение: число подключений и размер баз через отдельного пользователя только для чтения.

### 4.3 Сайты (3–4 шт.)
- отвечает ли (HTTP-код);
- время ответа;
- срок действия SSL-сертификата;
- срок регистрации домена.

Поиск определённого текста на странице не нужен.

### 4.4 Частота
Все проверки раз в минуту. Проверки сайтов и доступности идут из нескольких стран (с серверов в США, Нидерландах и России).

## 5. Оповещения

**Каналы:** уведомления macOS. Push на iPhone нужен, но откладывается до появления аккаунта Apple Developer (см. раздел 10).

**События (все включены):**
- сервер, сайт или сервис упал или снова поднялся;
- превышен порог: диск больше 90%, CPU больше 90% дольше 5 минут, память (порог настраивается);
- SSL-сертификат или домен истекает через 14 дней или раньше;
- AmneziaVPN остановился.

**Уровни важности:** «критично» (падение сервера, сайта, VPN, базы) и «предупреждение» (пороги, сроки истечения). Пороги и уровни настраиваются для каждого объекта.

**Защита от спама:**
- оповещение отправляется только после 2–3 неудачных проверок подряд;
- пока проблема не решена, напоминание повторяется раз в 30 минут;
- при восстановлении приходит одно сообщение «снова в норме».

**Получатели:** только пользователь. Нужна возможность добавлять свои новые устройства для получения уведомлений (новый Mac, позже iPhone).

## 6. Интерфейс

### 6.1 Строка меню
- значок с цветом общего состояния (зелёный, жёлтый, красный);
- выпадающий список всех объектов со статусом;
- быстрый переход в главное окно и к SSH.

### 6.2 Главное окно
- дашборд со всеми серверами и сайтами, сгруппированными по странам, хостингам или проектам;
- теги (например, «прод», «тест»), фильтр по группам и тегам;
- карточка сервера: графики метрик, сервисы, процессы, контейнеры, история событий;
- карточка сайта: время ответа, статус по странам, сроки SSL и домена;
- журнал оповещений;
- кнопка «SSH» открывает Терминал (или iTerm) с подключением к серверу.

### 6.3 Добавление объектов
- **Сервер:** в приложении нажимаю «Добавить сервер», получаю одну команду установки агента с уникальным ключом, запускаю её на сервере, сервер появляется в списке.
- **Сайт:** ввожу адрес, выбираю, из каких стран проверять.

Действия с сервером в первой версии: только просмотр и SSH. Перезапуск сервисов и серверов из приложения отложен на будущее.

## 7. Хранение данных

- подробные данные (поминутно) хранятся 30 дней;
- после этого данные сжимаются до почасовых и хранятся до года;
- всё хранится локально на Mac (позже на Mac mini).

## 8. Безопасность

- SSH-пароли и ключи хранятся в связке ключей macOS (Keychain), не в файлах приложения.
- Связь Mac с агентами только по HTTPS, агент принимает запросы только с секретным ключом, выданным при установке.
- Агент работает с минимальными правами, только читает данные и ничего не меняет на сервере.
- Предложение: порт агента на сервере открыть только для нужных адресов, где это возможно (домашний IP может меняться, поэтому основная защита это ключ и шифрование).
- Рекомендация вне приложения: постепенно перевести все серверы на вход по SSH-ключу и отключить вход по паролю.

## 9. Масштаб

- до 10 серверов и примерно 5 сайтов в ближайший год;
- один пользователь, многопользовательский режим не нужен;
- архитектура должна позволять добавлять серверы без изменения кода.

## 10. Бюджет и ограничения

- Отдельный VPS под мониторинг не нужен, всё работает на Mac.
- Аккаунта Apple Developer ($99 в год) пока нет и заводить его сейчас не планируется. Mac-приложение для себя можно собрать и запускать без него. Для push на iPhone и iPhone-приложения он понадобится.

## 11. Кто делает и в каком порядке

Код пишет Claude, пользователь проверяет и тестирует.

**Этап 1, быстрая версия (цель: 2–4 недели):**
- агент для Ubuntu и команда установки;
- приложение на Mac: строка меню и главное окно;
- мониторинг серверов, сайтов, AmneziaVPN, PostgreSQL и MySQL;
- уведомления macOS, правила и защита от спама;
- SSH в один клик, Keychain;
- хранение истории, группы и теги.

**Этап 2:**
- переезд «мозга» на Mac mini;
- проверки из разных стран и сравнение доступности (если не войдут в этап 1).

**Этап 3 (после появления аккаунта Apple Developer):**
- iPhone-приложение: push-уведомления и просмотр статусов.

**Позже:**
- перезапуск сервисов и серверов из приложения.
