# Контекст дизайна приложения на Mac

Этот файл задаёт, для кого и в каком духе делается интерфейс. Им проверяется каждое решение по UI.
Структура экранов и их содержимое описаны в [`ui-shape.md`](ui-shape.md).

## Кто пользуется

Один человек, владелец 10 серверов (RU, NL, US) и 3–5 сайтов. Технически грамотный: сам ходит
по SSH, знает, что такое load average и WireGuard. Приложение открывает в двух ситуациях:

1. **Беглый взгляд** (90% случаев). Глянул на значок в строке меню, всё зелёное, закрыл.
   Или пришло уведомление: надо за 5 секунд понять, что сломалось и насколько серьёзно.
2. **Разбор** (10%). Что-то не так: открыть сервер, посмотреть графики за последние часы,
   найти виновный процесс или контейнер, нажать SSH.

Значит, главное в интерфейсе: мгновенно отвечать на вопрос «всё ли в порядке» и за один-два
клика доводить до SSH на проблемном сервере.

## Характер продукта

Инструмент, а не витрина. Три слова: **спокойный, плотный, точный**.

- Спокойный: когда всё хорошо, интерфейс почти бесцветный. Цвет появляется только там,
  где есть проблема. Зелёный не кричит: в норме это маленькая точка, а не заливка.
- Плотный: как Activity Monitor и Mail. Таблицы, строки по 22–24 pt, цифры рядом с названием.
  Никаких огромных плиток с одной цифрой.
- Точный: цифры с единицами и временем измерения, «устарело 3 мин назад» вместо молчаливо
  старых данных, честное «нет данных» вместо нуля.

Ориентиры: Activity Monitor, Mail, System Settings, Xcode (навигатор и инспектор), iStat Menus
(строка меню). Не ориентиры: веб-дашборды Grafana и SaaS-лендинги.

## Чего не делаем (антипаттерны «ИИшного» интерфейса)

- градиенты, свечения, стекло поверх стекла, неоновые акценты;
- сетки одинаковых карточек со скруглением 16 pt и тенью вместо таблицы;
- огромные цифры-«героев» на весь экран обзора;
- эмодзи и декоративные иконки в заголовках;
- собственные шрифты, свой цвет фона, свои кнопки вместо системных;
- фиолетово-синий «AI»-акцент; акцентный цвет берётся системный (что выбрано в настройках macOS);
- анимации ради анимаций; допустимы только системные переходы;
- пустые состояния с иллюстрациями-маскотами.

## Визуальные правила

**Компоненты.** Только системные: `NavigationSplitView`, `Table`, `List` с `.sidebar`,
`Form` с `.grouped`, `GroupBox`, `Gauge`, `Chart` (Swift Charts), `MenuBarExtra(.window)`,
`Settings`, `.inspector` при необходимости, `.searchable`, тулбар окна.

**Шрифты.** Системный SF Pro. Числа в таблицах и графиках моноширинными цифрами
(`.monospacedDigit()`), чтобы столбцы не прыгали при обновлении. Иерархия через `.headline`,
`.body`, `.callout`, `.caption` и `.secondary`, без своих размеров.

**Цвет статуса** (единый словарь во всём приложении):

| Статус | Цвет | Значение |
|---|---|---|
| норма | `.green` | все проверки проходят |
| предупреждение | `.yellow` (на светлом фоне `.orange` для текста) | превышен порог, скоро истекает SSL или домен |
| критично | `.red` | не отвечает сервер, сайт, VPN или база |
| нет данных | `.secondary` (серый) | агент не опрашивался, Mac спал, данные старше 3 интервалов |
| отключено | без точки, текст `.tertiary` | объект на паузе |

Статус никогда не передаётся только цветом: у точки есть форма в символе SF Symbols
(`checkmark.circle.fill`, `exclamationmark.triangle.fill`, `xmark.octagon.fill`,
`questionmark.circle`) там, где хватает места, и текстовая подпись для VoiceOver.

**Графики.** Линия без заливки или со слабой заливкой 10%. Одна ось Y с единицами, сетка
приглушённая. Пороги рисуются пунктирной линией `RuleMark`. Наведение показывает точное
значение и время. Пропуски данных (Mac спал) остаются разрывом, а не соединяются линией.

**Плотность.** Окно по умолчанию 1200 × 760, минимум 900 × 560. Все таблицы сортируются
по любому столбцу, выбор колонок через контекстное меню заголовка.

**Тёмная и светлая темы** работают автоматически, потому что используются только
семантические цвета.

## Тексты

- Русский язык, коротко и по делу: «Не отвечает 4 мин», «SSL истекает через 9 дней»,
  «Диск / 93%».
- Время относительное в списках («2 мин назад»), абсолютное во всплывающей подсказке и журнале.
- Единицы: %, ГБ, МБ/с, мс; байты в человекочитаемом виде (`ByteCountFormatter`).
- Кнопки глаголом: «Добавить сервер», «Открыть SSH», «Скопировать команду».

## Поведение

- Клавиатура: ⌘1…⌘6 разделы боковой панели, ⌘F поиск, ⌘N добавить сервер, ⇧⌘N добавить
  сайт, ⌘⇧S SSH на выбранный сервер, ⌘R опросить сейчас, ⌘, настройки.
- Контекстное меню на любой строке объекта: SSH, Скопировать адрес, Опросить сейчас,
  Пауза оповещений на 1 ч, Изменить.
- Данные обновляются на месте без мигания и сброса выделения и прокрутки.
- Приложение живёт в строке меню; закрытие главного окна не завершает приложение.
