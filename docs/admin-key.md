# Ключ администратора (Рутокен Lite)

Пока ключ не настроен, приложение работает как раньше. После настройки оно
запускается заблокированным и ничего не показывает, пока не вставлен Рутокен
и не введён PIN. Если вынуть токен, приложение сразу снова блокируется и
показывает окно «Вставьте ваш токен». Мониторинг при этом продолжает
работать в фоне.

## Как устроено

- При настройке приложение записывает на токен случайный секрет (32 байта) как
  закрытый объект данных PKCS#11: прочитать его можно только после ввода PIN.
- В Связке ключей хранится только серийный номер токена, SHA-256 секрета и
  хэш кода восстановления. Сам секрет, PIN и код восстановления нигде не
  сохраняются.
- Вход: токен с тем же серийным номером, верный PIN, секрет совпадает с хэшем.
- Токен проверяется раз в секунду (`AdminLock.startWatching`); статус
  `presence` говорит экрану блокировки, вставлен ли нужный токен, чужой или
  никакого. По времени блокируется только вход по коду восстановления: через
  15 минут без изменений.
- Код восстановления показывается один раз при настройке. Он открывает
  приложение без токена, чтобы записать новый токен.
- Все входы, неудачные попытки и отказы пишутся в журнал «Действия».
- Рутокен Lite сам не подписывает, поэтому тот, у кого есть и токен, и PIN,
  может скопировать секрет. Для входа на своём Mac этого достаточно; позже
  `AdminKey` можно заменить на FIDO2 (Рутокен MFA) без переделки остального.

## Установка драйвера (один раз)

1. Откройте в Safari сайт rutoken.ru, раздел «Поддержка» → «Центр загрузки» →
   «Драйверы для macOS».
2. Скачайте модуль PKCS#11 для macOS (библиотека rtpkcs11ecp) и откройте
   скачанный файл .pkg.
3. Нажимайте «Продолжить» и «Установить», введите пароль от Mac, когда
   система попросит.
4. Вставьте Рутокен и откройте в приложении «Настройки» → «Ключ
   администратора». Если драйвер найден, там появится ваш токен.

Если PIN токена всё ещё заводской (12345678), приложение попросит сменить его
прямо в том же окне.

## Для разработки

`MonitorCore/PKCS11.swift` загружает библиотеку через dlopen из
`PKCS11.rutokenPaths`, поэтому приложение собирается и запускается без
драйвера. Тесты гоняют тот же код на SoftHSM (пакет softhsm2), если он
установлен.
